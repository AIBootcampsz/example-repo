PROJECT:

Triathlon Award Calculator

DESCRIPTION:

A Python program that calculates a participant’s total triathlon time and displays the appropriate award based on the combined swimming, cycling, and running times.

INSTALLATION:

Install the latest version of Python. Save the code in a file named triathlon_award.py.

USAGE:

Run the program in the Python terminal window.
Enter the time taken for each activity (swimming, cycling, and running) in minutes when prompted.
The program adds the three whole-number times together and uses the total to determine the award.
For example, 30 + 45 + 25 = 100, which results in Provincial colours.

AWARD CRITERIA:

Total time            | Award 

111 minutes or more   | No award

106–110 minutes      | Provincial scroll

101–105 minutes       | Provincial half colours

100 minutes or less    | Provincial colours
